# UnderCooked 제출물

| 항목 | 내용 |
| --- | --- |
| 프로젝트 이름 | UnderCooked |
| 설명 | UnderCooked는 두 에이전트가 분리된 주방 구역에서 협력해 수프를 완성하고 서빙하는 강화학습 환경이다. 재료와 냄비는 Chef A 구역에, 접시와 서빙구는 Chef B 구역에 있어 카운터를 통한 물건 전달이 반드시 필요하다. 두 에이전트는 팀 보상을 바탕으로 재료 투입, 접시 전달, 수프 전달, 서빙까지의 순차적 협업 정책을 학습한다. 16개의 독립된 Training Area를 동시에 실행해 학습 데이터를 수집한다. |
| 사용 심화 개념 | **MA-POCA + Team ID**: 두 Chef를 한 팀으로 묶어 공동 목표 보상으로 협력 정책을 학습한다.<br>**Action Masking**: 이동 불가능한 방향과 현재 상태에서 의미 없는 상호작용을 마스킹해 탐색 공간을 줄인다. |
